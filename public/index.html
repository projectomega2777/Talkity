Capabilities

Built for the way you actually write.

A dictation layer that stays quiet until you need it — then puts your words exactly where the cursor is. Every card below is checked against the shipped code; the badge tells you where it runs.

Web + desktop

Voice-to-text in your browser

The demo on this page records with your microphone and transcribes through the same endpoint as the desktop app. Nothing to install, no account.

Web + desktop

Whisper large-v3 transcription

Speech is transcribed by Whisper large-v3 on Groq, with OpenAI Whisper as a fallback. The browser demo and the Windows app share the pipeline.

Web + desktop

Whisper language support

Auto-detect handles English, Hindi and Hinglish. Pin the source language per request. The offline Windows engine adds four English locales.

Windows app

Global hotkey

F8 by default, registered with Windows so it fires while another app has focus. Remap it to F6–F10, Ctrl+Shift+Space or Ctrl+Space.

Windows app

Types at the caret

The transcript is inserted where your cursor is — Notepad, Word, Slack, a browser, any app that accepts text. Your clipboard is preserved and restored.

Web + desktop

Custom vocabulary

A shared dictionary maps the phrases speech models mishear to the spelling you want — names, products and jargon sent with every request.

Windows app

Transcription history

A bounded local history — 10 to 1000 entries, 100 by default — stored in %APPDATA%\Talkity\history.json. Reinsert any entry, or turn it off.

Windows app

Floating desktop HUD

A small always-on-top pill shows listening, processing and the timer while you dictate. Drag it anywhere; the position is remembered between sessions.

Windows app

Optional AI polish

Deterministic cleanup — spacing, punctuation, capitalisation and dictionary spellings — runs everywhere. The Windows app adds an optional AI pass with five tones.

How it works

Three steps, then it disappears.

  1. 01

    Install

    Download the Windows installer and run it. Windows 10 or 11 with .NET Framework 4.5 or later.

  2. 02

    Press and speak

    Hit your global hotkey, speak naturally, and press it again to stop. The HUD shows listening and processing.

  3. 03

    Keep working

    The transcript lands at your cursor in the app you were already using, formatted and ready to send.

No install yet? Try the browser demo — it records, transcribes and lets you copy the result, but only the Windows app can type into other programs.

Compatibility & privacy

Know exactly what runs where.

The demo on this page is a real transcription client, not the desktop app. Here is the honest split, and what happens to your audio.

In this browser

Chrome · Edge · Firefox · Safari

  • Records from your microphone only after you press Start
  • Transcribes through the same Whisper endpoint as the desktop app
  • Copy the result, or clear it and record again
  • No global hotkey
  • Cannot type into other applications
  • No history, HUD or tray icon

In the Windows app

Windows 10 / 11 · .NET Framework 4.5+

  • Global hotkey that works while another app is focused
  • Inserts text at the caret in any text field
  • Local history, floating HUD, tray icon and launch at login
  • Optional AI polish with five tones
  • Windows only

Microphone

Permission is requested only when you press Start speaking. Every audio track is stopped when you stop, clear, leave the tab or hit an error — nothing keeps recording in the background.

Audio & transcripts

The clip is sent once to Talkity’s transcription service (Whisper on Groq, with OpenAI as a fallback). This site does not store the audio or the transcript; reloading the page clears it.

Rate limits

AI endpoints allow 35 requests per minute per IP. If you hit the limit, the demo tells you how long to wait instead of retrying silently.

HTTPS required

Browsers only grant microphone access on HTTPS or localhost. On an insecure origin the demo explains the problem rather than failing silently.

Questions

Everything you might ask before installing.

Which versions of Windows are supported?

Windows 10 and Windows 11. The installer checks for .NET Framework 4.5 or later and explains what to install if it is missing.

Do I need an account or an API key?

No account is required. Install the app, grant microphone access when Windows asks, and start dictating.

Does it work offline?

Whisper transcription runs on the Talkity service, so dictation needs an internet connection. If you would rather stay local, you can switch to the built-in Windows speech engine in settings.

Which applications does it work with?

Any Windows app that accepts typed text — Notepad, Word, browsers, chat and email clients. Text is inserted at the caret, with a clipboard fallback when no target window can be captured.

Why does Windows warn that the publisher is unknown?

The installer is not code-signed yet, so SmartScreen shows an “unknown publisher” prompt. Choose “More info”, then “Run anyway” to continue.

What happens to my audio in the browser demo?

The microphone opens only after you press Start speaking. The clip is sent once to Talkity’s transcription service, turned into text, and discarded — this site does not store the audio or the transcript. Reloading the page clears everything.

Which browsers can run the demo?

Recent versions of Chrome, Edge, Firefox and Safari, served over HTTPS or localhost. The browser must support microphone capture and the Web Audio API; if it does not, the demo says so instead of showing a broken recorder.

Why can’t the demo type into my other apps?

A web page is sandboxed and cannot press a system-wide hotkey or insert text into another program. That is exactly what the Windows app adds: a global hotkey, caret insertion and a floating HUD.

Can I try it without installing anything?

Yes — the live demo records in your browser and uses the same transcription pipeline. The desktop app is what gives you the global hotkey and insertion into other apps.
